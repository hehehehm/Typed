# Typed

Раньше программа называлась LayoutKeeper. Typed — от *type daemon*: демон, который следит за набором текста.

Утилита в духе Punto Switcher / Caramba Switcher для Windows, macOS и Linux (X11):

1. **Раскладка по умолчанию для каждого приложения.** Назначили Telegram русский — раскладка
   становится русской при каждом переходе в Telegram. Ручное переключение раскладки внутри
   приложения назначение **не меняет** (с версии 0.2.0).
2. **Автоисправление неправильной раскладки.** Набрали `зуфсу` (хотели `peace`) —
   слово заменится на `peace`, а раскладка переключится. Обратное тоже работает: `ghbdtn` → `привет`.
3. **Ручная конвертация** последнего слова горячей клавишей (по умолчанию Pause/Break; повторное нажатие — отмена).
   Сочетание выбирается в окне настроек.
4. **Вызов окна настроек и сейфа** отдельной горячей клавишей (по умолчанию `Ctrl+Shift+V`):
   выделили поле, вызвали программу — откроется вкладка «Сейф», нажали логин или карту для вставки.

Работает **только локально**: никакой сети, телеметрии и аналитики. Подробности — в разделе «Безопасность».

## Установщик Windows для тестеров

Собирать на Windows 11:

1. Установите Rust через <https://rustup.rs/> (если ещё не установлен).
2. Установите **Inno Setup 6** с <https://jrsoftware.org/isinfo.php>. Подойдёт установка только для текущего пользователя.
3. Из корня проекта запустите:

```powershell
powershell -ExecutionPolicy Bypass -File packaging\windows\build-installer.ps1
```

Скрипт выполнит `cargo build --release` и соберёт **`dist\LayoutKeeper-Setup-0.3.9.exe`**.
Отправьте тестерам этот **один файл**; Rust и Inno Setup им не нужны.
Сам скрипт можно вызывать из любой папки, указав полный путь к нему.

- Права администратора не требуются: программа устанавливается в `%LOCALAPPDATA%\Typed`.
- В меню «Пуск»: **LayoutKeeper** (демон с консолью для логов) и **LayoutKeeper — настройки** (`gui`). Ярлык настроек на рабочем столе — по желанию, по умолчанию выключен.
- Автозапуск при входе в Windows включён по умолчанию: ярлык в папке автозагрузки текущего пользователя вызывает `start-hidden.vbs`, чтобы демон работал без консоли. Нужен Windows Script Host (если он отключён политикой, запустите демон через «Пуск»).
- После установки по умолчанию запускаются демон без консоли и настройки; оба флажка можно снять. Не запускайте второй демон вручную, если он уже работает.
- Окно настроек также вызывается `Ctrl+Shift+V` (вкладка «Сейф»), если демон запущен и сочетание не изменено. В уже сохранённых настройках может остаться прежнее сочетание. Само окно `gui` может сопровождаться консолью: бинарник остаётся консольным.
- При обновлении/удалении установщик попробует закрыть работающую программу; если попросит, закройте настройки и демон, сохранив изменения. Не запускайте новую копию поверх старой.
- Конфигурация и сейф лежат в `%APPDATA%\typed` и **не удаляются при деинсталляции** (если путь не переопределён через `LAYOUT_KEEPER_CONFIG`). При первом запуске `config.json`, `vault.bin` и `typed.chk` копируются из старой папки `%APPDATA%\layout-keeper`, если в новой их ещё нет.
- Установщик **не подписан**: SmartScreen может предупредить. Для доверенной копии: **«Подробнее» → «Выполнить в любом случае»** (если политика Windows разрешает). Не обходите предупреждения для неизвестных файлов.
- Антивирус может отметить программу из-за перехвата клавиатуры: заранее объясните тестерам, что это утилита раскладки/клавиатуры. Это не гарантия ложного срабатывания; проверяйте источник и предупреждение, не отключайте защиту вслепую.

Этот раздел добавляет только установщик Windows, не macOS.

## macOS: один .dmg для тестеров

Сборка выполняется **на Mac**:

1. Установите инструменты Xcode Command Line Tools: `xcode-select --install`.
2. Установите Rust с <https://rustup.rs/>, если его ещё нет; откройте новый Терминал.
3. Распакуйте исходники, перейдите в корень проекта (где `Cargo.toml`) и выполните:

```bash
./packaging/macos/build-dmg.sh
# или: bash packaging/macos/build-dmg.sh
```

Скрипт сам найдёт корень проекта, выполнит `cargo build --release`, создаст
`dist/Typed.app` и **`dist/Typed-<версия>.dmg`** (сейчас `dist/Typed-0.3.68.dmg`). Отправьте тестерам этот
**один .dmg**; Rust им не нужен. Образ рассчитан на архитектуру Mac, где он собран
(Apple Silicon или Intel); универсальная сборка здесь не выполняется.
Дополнительные упаковщики не нужны; скрипт не скачивает их и не выполняет нотаризацию.
Cargo при первой сборке может потребоваться доступ к зависимостям.

**Тестерам:** откройте .dmg и перетащите Typed в «Программы» (Applications).
Запускайте установленную копию, не копию внутри образа. При запуске обёртка .app
запускает демон в фоне и открывает настройки (`gui`). Не запускайте второй демон,
если он уже работает; закрытие настроек не останавливает фоновый демон.

- Неподписанные/ad-hoc сборки вызывают предупреждение Gatekeeper. Для доверенной
  копии попробуйте правый клик → **«Открыть»**. Если macOS не предлагает такой запуск,
  после попытки откройте «Системные настройки → Конфиденциальность и безопасность»
  и используйте **«Всё равно открыть»**, если эта возможность доступна по политике Mac.
  Это не гарантирует разрешение запуска; не отключайте Gatekeeper.
- Выдайте LayoutKeeper **«Универсальный доступ» (Accessibility)** и
  **«Мониторинг ввода» (Input Monitoring)** в **«Системные настройки →
  Конфиденциальность и безопасность»**. Без этих разрешений клавиатурный хук
  не будет нормально работать. После выдачи разрешений перезапустите приложение/демон.
- Подпись ad-hoc (`codesign --force --sign -`) не является подписью Developer ID
  и не снимает предупреждения у тестеров. Скрипт лишь предупреждает, если она не удалась.
- Нотаризация необязательна и требует платного аккаунта **Apple Developer**.
  Для распространения без этих предупреждений отдельно подпишите вложенный бинарник
  и приложение через `codesign` сертификатом Developer ID Application с hardened runtime
  и timestamp, затем подпишите образ, отправьте его через `xcrun notarytool submit --wait`
  и после принятия прикрепите билет через `xcrun stapler staple`.
  Сертификат (например, `Developer ID Application: Your Name (TEAMID)`) и профиль
  авторизации notarytool принадлежат вам; скрипт не запрашивает Apple ID и не хранит секреты.

## Что нового в 0.3.68

- **Свёрнутое в трей окно настроек больше не занимает процессор.** Настоящая причина 6% CPU была не в Typed, а в оконной библиотеке eframe 0.29.1: Windows не присылает спрятанному окну событий перерисовки, а eframe после любой просьбы перерисовать окно переводил цикл событий в режим «опрашивать без остановки» и ждал этой перерисовки вечно. Одно ядро процессора крутилось вхолостую (6,25% = одно ядро из 16), поэтому прошлые ограничители кадров внутри Typed не помогали: до них дело просто не доходило. В Typed встроена исправленная копия eframe 0.29.1 (`third_party/eframe`, перенос исправления из egui PR #7905): спрятанное или свёрнутое окно рисуется напрямую не чаще 4 раз в секунду и только по запросу, цикл событий спит. Трей, вызов по `Ctrl+Shift+V`, закрытие крестиком в трей, «Выход» и автоблокировка сейфа работают как раньше.
- **Программа теперь называется `typed.exe`** (раньше `layout-keeper.exe`). Установщик сам останавливает старый `layout-keeper.exe` и задачу «Typed», удаляет старый файл и переводит ярлыки, автозагрузку и деинсталлятор на `typed.exe`. Если включён «Запуск администратором», задача после обновления перерегистрируется на `typed.exe` (Windows один раз спросит разрешение). Если задача всё же осталась старой, в «Настройках» появится кнопка «Обновить задачу». Конфиг и сейф остаются в `%APPDATA%\typed`, установка — в `%LOCALAPPDATA%\Typed`.

## Что нового в 0.3.67

- **Галочка «Запуск администратором»** (Windows, вкладка «Настройки»). Windows не даёт обычной программе переключать раскладку в программах, запущенных от имени администратора (MobaXterm, PowerShell и т. п.). Поэтому Typed, запущенный с обычного ярлыка, не мог переключать в них язык, а запущенный из PowerShell администратора — мог. С галочкой Typed запускается при входе в Windows через Планировщик заданий (задача «Typed») с правами администратора и без окна с вопросом. Windows спрашивает разрешение один раз — при включении (и при выключении). Обычный ярлык автозагрузки при включённой галочке сам передаёт запуск этой задаче, поэтому Typed по-прежнему работает в одном экземпляре. Если Typed почему-то работает без прав, в «Настройках» появится предупреждение и кнопка «Перезапустить с правами администратора». Снятая галочка удаляет задачу, со следующего входа Typed запускается как раньше. Деинсталлятор тоже удаляет задачу. В config.json это поле `run_as_admin`.
- **Опечатки исправляются и в более редкие слова.** Раньше вариантом исправления могли быть только 20 тыс. самых частых слов, хотя в списке их 40 тыс. Поэтому «ярдык» не становился «ярлык» (оно ≈30 700-е по частоте), так же как minute, serve, member и тысячи других. Теперь в расчёт идёт весь список. Более редкая половина побеждает, только если опечатка внутри слова и последние две буквы совпадают: так незнакомые имена не превращаются в другие редкие слова. На тесте из ≈9 тыс. опечаток правильно исправляется RU 58,4% → 76,2%, EN 40,2% → 72,4%. Исправлений не на то слово стало меньше: RU 4,0% → 1,5%, EN 6,6% → 2,2%. Настоящие слова из полного словаря по-прежнему не трогаются.
- Версия видна в заголовке окна: «Typed (ver. 0.3.67)».

## Что нового в 0.3.65

- **Свёрнутое окно настроек больше не грузит процессор.** Свёрнутое окно Typed прятал в трей заново на каждом кадре, а каждая такая команда снова будила окно, отсюда ~6% CPU. Теперь окно прячется один раз, а свёрнутое или спрятанное окно ничего не рисует. Пока сейф открыт, раз в минуту проверяется автоблокировка.
- **Бренды и названия.** Typed знает ≈14,2 тыс. новых латинских названий (телефоны, техника, машины, одежда, софт, приложения, игры, сайты, крипта, еда и напитки, магазины) и ≈6,4 тыс. русских написаний популярных брендов со всеми падежами («реалми», «сяоми», «айфона», «айфоном», «самсунга», «ютубе», «телеграме»). Источники: Wikidata (CC0) и ручной список. `realme` больше не исправляется в `realm`, а `куфдьу` превращается в `realme`. Названия только «известны»: Typed их не трогает, но и не подставляет как исправление. Названия короче 4 букв и те, что в другой раскладке дают настоящее слово, не добавлены, поэтому перевод раскладки работает как раньше (100% на тесте).
- **Английские слова, отличающиеся одной последней буквой, больше не «исправляются»** (realme → realm, appl → apple). Удвоенная последняя буква по-прежнему исправляется (helloo → hello). На тесте ложных исправлений редких английских слов стало меньше (10,4% → 8,6%), а настоящие опечатки исправляются даже чуть лучше (76,2% → 78,4%).
- **Пропущенные пробелы после предлогов и «не».** «снейросеткой» → «с нейросеткой», «вофисе» → «в офисе», «кврачу» → «к врачу», «нафайле» → «на файле», «незнаю» → «не знаю». Срабатывает, только когда слова нет ни в одном словаре, вторая часть — частое слово с подходящим к предлогу окончанием, не имя и (кроме «не») не глагол. Настоящие слова не разбиваются (0 из 63 тыс. проверенных словоформ). Отменяется так же, как исправление: Backspace или `Ctrl+Alt+Z`. Выключается галочкой «Расставлять пропущенные пробелы» в «Настройках» (`fix_missing_spaces` в config.json), в приложениях-исключениях не работает.

## Что нового в 0.3.64

- **Словарь всех форм слов.** Typed теперь знает 3,16 млн русских словоформ (все падежи, числа, роды, времена, причастия, деепричастия) и 810 тыс. английских: OpenCorpora, Hunspell ru_RU / en_US / en_GB, SCOWL, Викисловарь (kaikki.org), wordfreq. Настоящее слово, даже редкое («скидывать», «скидываешь», «скидывавшимися»), больше не «исправляется» в другое. Опечатки по-прежнему исправляются только на частые слова. Ложных исправлений на редких словах стало сильно меньше: RU 8,7% → 1,5%, EN 13,9% → 4,1%. Опечатки исправляются почти так же, как раньше: на тесте 77,6% → 77,0%. Словари встроены в программу в сжатом виде (fst), сети по-прежнему нет. Программа выросла примерно на 5,5 МБ, на запуск и память это почти не влияет. Источники и лицензии описаны в `crates/core/data/README.md`.
- **Отмена автоисправления: `Ctrl+Alt+Z`** (на macOS `Ctrl+Option+Z`). Сочетание меняется в «Настройках». Сразу после исправления оно возвращает слово ровно таким, каким вы его набрали, вместе с пробелом или знаком после него. Раскладка тоже возвращается. Слово попадает в список «Не исправлять» и больше никогда не исправляется.
- **Backspace сразу после исправления тоже отменяет его**, как в Punto Switcher. Срабатывает только первый Backspace, пока не нажато ничего другого, и не после Enter/Tab. Слово запоминается, когда вы продолжаете печатать дальше. Если стереть его целиком, оно не запоминается. Это поведение можно выключить в «Настройках».
- **Typed больше не повторяет ошибку.** Если стереть исправленное слово и набрать его заново так же, Typed его оставит и запомнит. Это работает и с `Ctrl+Backspace` / `Option+Delete`. Клавиша конвертации сразу после автоисправления теперь тоже работает как отмена.
- Список «Не исправлять» показан во вкладке «Свои слова». Корзина рядом со словом снова разрешает его исправлять. В config.json это поля `never_correct`, `undo_hotkey` и `undo_on_backspace`, старые конфиги читаются без изменений.

## Что нового в 0.3.62

- Вкладка «Раскладки»: у каждой запомненной программы есть кнопка со стрелкой вниз «Скрыть в системные». Программа уходит в свёрнутую группу «Скрытые и системные», а стрелкой вверх «Вернуть в список» возвращается обратно. Скрытие только визуальное: раскладка для скрытых программ ставится как раньше. Список скрытых хранится в config.json (`hidden_apps`), старые конфиги читаются без изменений.
- Опечатки исправляются осторожнее:
  - Правильные формы, которых нет в словаре, больше не «исправляются»: глаголы (оцени, оценю, проверь, исправьте, разбери, удаляю), прилагательные и существительные в падежах (файлами, раскладке, системному), английские формы (typos, installer, uninstall, layouts). Раньше «оцени» становилось «олени».
  - Typed больше не выдаёт несуществующих слов: «ситстемрым» теперь даёт «системным», а не «системым». Новую форму слова он собирает, только если по словарю ясно, что это за слово (существительное или прилагательное). Глагольные формы он только узнаёт, но сам не собирает.
  - Заменённая буква засчитывается, только если её клавиша стоит рядом с нужной. В словах от 6 букв ещё допускаются гласная вместо гласной и пары б/п, в/ф, г/к, д/т, ж/ш, з/с. Первая буква не меняется, разрешена только перестановка двух первых. Одно окончание вместо другого тоже не считается опечаткой («удаляю» не превратится в «удалю»).
  - Перестановка соседних букв считается самой вероятной ошибкой: «компьютре» → «компьютер», «recieve» → «receive».
  - Две перестановки в слове из 7 букв тоже исправляются: «влкдаки» → «вкладки». В словарь добавлены слова интерфейса: вкладка, раскладка, системный, настройка, опечатка.
- Установщик Windows перед установкой молча удаляет предыдущую версию, в том числе старую из папки LayoutKeeper. Настройки, сейф и ключ (`%APPDATA%\typed`: config.json, vault.bin, typed.chk) не трогаются.

## Что нового в 0.3.60

## Сборка и запуск

Нужен Rust ≥ 1.80 (`rustup`). Внешних системных библиотек для сборки не нужно
(на Linux libX11/libXtst подгружаются при запуске).

```bash
cargo test                       # тесты ядра и контроллера
cargo build --release
./target/release/typed   # = typed run
```

Команды:

| Команда | Что делает |
|---|---|
| `typed` / `typed run` | запустить фоновый процесс (путь к конфигу печатается при старте) |
| `typed gui` | открыть окно настроек (демон запускается отдельно) |
| `typed status` | конфиг, настройки, активное приложение и текущая раскладка |
| `typed set-app <app-id> <en\|ru>` | запомнить раскладку для приложения |
| `typed remove-app <app-id>` | забыть приложение |
| `typed list-apps` | список запомненных приложений |
| `typed set autocorrect on\|off` | включить/выключить автоисправление |
| `typed set auto-learn on\|off` | авто-запоминание ручных переключений |
| `typed set hotkey <Combo>` | горячая клавиша ручной конвертации (`Pause`, `Ctrl+Shift+P`, …) |
| `typed set summon-hotkey <Combo>` | вызов окна настроек на вкладке «Сейф» (по умолчанию `Ctrl+Shift+V`) |
| `typed convert <текст>` | перепечатать текст в другой раскладке (`ghbdtn` → `привет`) |
| `typed check <слово>` | показать решение автокоррекции и причину |

Работающий процесс подхватывает изменения конфига (через CLI или вручную) примерно за секунду.
Логи идут в stderr: `RUST_LOG=debug typed` — подробнее (длины слов и решения, **не сами слова**).

Автозапуск: Windows — ярлык в `shell:startup`; macOS — LaunchAgent (`~/Library/LaunchAgents`);
Linux — `~/.config/autostart/typed.desktop` или systemd user unit. Трея пока нет.

## Графические настройки (`typed gui`)

Окно настроек — отдельный процесс: он только редактирует тот же `config.json`, а работающий демон
(`typed` / `typed run`) подхватывает изменения примерно за секунду. Демон с
перехватом клавиатуры нужно держать запущенным отдельно — окно его не заменяет.

```powershell
.\target\release\typed.exe gui
```

* **Текущее приложение** — окно следит за активной программой (своё окно пропускает). Переключитесь
  в нужную программу, вернитесь в настройки и нажмите «Назначить EN» или «Назначить RU».
  Показываются также раскладка сейчас и уже назначенная.
* **Запомненные приложения** — для каждого можно выбрать EN/RU или удалить иконкой корзины; список сортируется по числу запусков; можно добавить id вручную.
* **Настройки** — автоисправление, перевод однобуквенных слов в назначенный язык приложения, автозапоминание и горячие клавиши. Сочетание можно назначить кнопкой «Назначить» (нажать нужные клавиши) или выбрать из готовых. Отдельно задаётся вызов окна — по умолчанию `Ctrl+Shift+K`, чтобы открыть сейф, не отрываясь от поля ввода.

На Windows при запуске из ярлыка рядом будет консольное окно (бинарник консольный).

## Сейф паролей и карт (с версии 0.3.0)

Откройте окно через `typed gui` или глобальную клавишу вызова (по умолчанию `Ctrl+Shift+K`) → вкладка **«Сейф»**.
Типичный сценарий: кликните в поле ввода, нажмите клавишу вызова, затем кнопку вставки логина или карты.

* **Локально и зашифровано.** Файл `vault.bin` лежит рядом с `config.json`
  (Windows: `%APPDATA%\typed\vault.bin`). На диске только шифротекст:
  ключ из мастер-пароля через **Argon2id** (64 МиБ, 3 прохода, случайная соль),
  шифрование **XChaCha20-Poly1305** (случайный nonce при каждом сохранении). `config.json` секретов не содержит.
* **Мастер-пароль восстановить нельзя.** При создании вводится дважды (не короче 8 символов).
* Сейф расшифровывается только в памяти окна настроек и блокируется кнопкой «Заблокировать»,
  при закрытии окна и после бездействия (по умолчанию 10 мин, настраивается). Ключ и записи затираются (`zeroize`).
* **Ничего не собирается с клавиатуры.** Перехватчик клавиш демона в сейф не пишет;
  записи появляются только когда вы сами добавляете их в окне.
* Логины: название, имя пользователя, пароль, заметки, часть пути приложения/адреса для подсказки
  (логин подсвечивается «★ подходит», если путь текущего приложения её содержит).
* Карты: название, номер, срок ММ/ГГ, имя, CVC — **необязательно** (особо чувствительные данные; лучше не хранить).
* В списке видны только название, имя пользователя и **последние 4 цифры** карты. Пароль — только по кнопке «показать».
* **Подстановка только по нажатию кнопки.** Щёлкните в нужное поле другой программы, вернитесь в окно
  LayoutKeeper и нажмите «Подставить логин» (имя, Tab, пароль), «Только пароль», «Только имя пользователя»
  или для карты «Номер» / «Срок» / «Имя» / «CVC». Окно свернётся и наберёт текст в приложение, показанное
  как «Текущее приложение». Если фокус оказался на самом LayoutKeeper или на другой программе — ничего не набирается.
* Набирает сам процесс окна настроек (SendInput на Windows, XTest на Linux X11, CGEvent на macOS), без буфера обмена,
  без связи с демоном и без сети. На Windows/macOS демон игнорирует эти нажатия (помечены), автозамена их не трогает.
* `typed vault status` — только есть ли файл сейфа. Команд с паролями в аргументах нет намеренно.
* Ограничения: в окна, запущенные от администратора, Windows набирать не даёт; на Linux символы должны
  набираться в одной раскладке (только латиница или только кириллица), а демон видит XTest-нажатия как обычные;
  на Wayland подстановка не работает. Отдельный менеджер паролей (Bitwarden, KeePassXC) безопаснее:
  здесь ввод и сейф живут в одной программе.

## Разрешения ОС (честно)

| ОС | Что нужно | Зачем |
|---|---|---|
| **Windows** | ничего особенного, прав администратора не нужно | `WH_KEYBOARD_LL` и `SendInput` работают для обычного пользователя. Но окна, запущенные **от администратора**, обычный процесс не видит и не может в них печатать (UIPI) — там утилита просто ничего не делает. |
| **macOS** | **Input Monitoring** (Мониторинг ввода) и **Accessibility** (Универсальный доступ) в «Системные настройки → Конфиденциальность и безопасность» для терминала/бинарника | Input Monitoring — чтобы видеть нажатия (`CGEventTap`), Accessibility — чтобы стирать и печатать исправленное слово. Без Input Monitoring работает только память раскладки по приложениям. |
| **Linux X11** | ничего (нужны пакеты `libx11-6`, `libxtst6` и расширения RECORD/XTEST — есть почти везде) | XRecord видит клавиши всех X-клиентов, XTest печатает. Это особенность X11: любой X-клиент может это делать. |
| **Linux Wayland** | см. ниже | — |

Поля ввода паролей: в Windows/X11 утилита **не может надёжно определить**, что фокус в поле пароля.
Поэтому: менеджеры паролей и терминалы по умолчанию в исключениях — там никогда не работает
автозамена, но раскладка по приложениям по-прежнему запоминается и ставится; слова со смешанным
регистром, цифрами, `@`, `://` не трогаются; буфер слова живёт только в памяти. На macOS при
включённом Secure Input (поля паролей) система сама не отдаёт события в event tap.

## Как работает память раскладки по приложениям

* Идентификатор приложения: Windows — полный путь к `.exe` (в нижнем регистре), macOS — bundle id
  (`com.tinyspeck.slackmacgap`), Linux — `WM_CLASS` (класс окна), запасной вариант — имя процесса.
* **Назначение «липкое»:** при каждом переходе в приложение (открытие, смена фокуса) включается
  назначенная раскладка. Внутри приложения можно временно переключиться, чтобы что-то набрать —
  после первых ~3 секунд стабилизации фокуса утилита не возвращает раскладку насильно, но и **назначение не перезаписывает**. В следующий раз
  при переходе в приложение снова включится назначенная раскладка.
* Изменить назначение можно только явно: `typed set-app`, `remove-app` или в окне `gui`.
* Авто-обучение (`auto_learn`, для новых конфигов **выключено**): если включено, заполняет раскладку
  только для приложений, у которых назначения ещё нет (по ручному переключению или по раскладке, на
  которой приложение оставили). Уже назначенное оно **никогда** не перезаписывает.
* Обновление с 0.1.0: в существующем `config.json` останется `"auto_learn": true` — новое значение по
  умолчанию касается только новых файлов. Но правило «не перезаписывать назначенное» работает
  сразу, так что уже назначенные приложения после обновления не собьются. Чтобы новые приложения
  тоже не запоминались сами, выключите автозапоминание в `gui` или `typed set auto-learn off`.
* Исключения (`exception_apps`, подстрока, без учёта регистра): менеджеры паролей, терминалы,
  удалённые рабочие столы/VM. В этих приложениях **автозамена и горячая клавиша конвертации
  никогда не срабатывают**. Память раскладки работает как обычно: язык можно назначить в `gui`
  или `set-app`, и он будет ставиться при каждом открытии. Список можно править во вкладке «Исключения» окна `gui`.

Конфиг (`config.json`): Linux `~/.config/typed/`, macOS `~/Library/Application Support/typed/`,
Windows `%APPDATA%\typed\`. При первом запуске файлы копируются из прежней папки `typed`, если новых ещё нет. Переопределить путь: `LAYOUT_KEEPER_CONFIG=/path/config.json`.

```json
{
  "apps": { "firefox": "en", "telegramdesktop": "ru" },
  "auto_learn": false,
  "autocorrect": true,
  "convert_single_letters": true,
  "exception_apps": ["keepass", "1password", "terminal", "..."],
  "hotkey": "Pause",
  "summon_hotkey": "Ctrl+Shift+V",
  "undo_hotkey": "Ctrl+Alt+Z",
  "undo_on_backspace": true,
  "never_correct": ["скидывать"],
  "skip_urls_emails": true,
  "skip_tokens_with_digits": true,
  "min_word_len": 2
}
```

## Как работает автоисправление

Ядро (`layout_keeper_core`) не зависит от ОС:

1. **Карта физических клавиш** US QWERTY ↔ ЙЦУКЕН (буквы, `[ ] ; ' , . / \``, оба регистра,
   отличающиеся символы цифрового ряда). `зуфсу` ↔ `peace`, `руддщ` ↔ `hello`, `ghbdtn` ↔ `привет`.
2. **Буфер текущего слова** в памяти: Backspace стирает, пробел/Enter/Tab/пунктуация завершают слово;
   клик мышью, стрелки, Home/End, Escape, смена окна — сбрасывают буфер. Символы вроде `,` `.` `;` `[`
   считаются частью слова, потому что в другой раскладке это буквы (`,eltn` → `будет`).
3. **Решение** при завершении слова (по порядку):
   * нажаты Ctrl/Alt/Super/Cmd — это сочетание клавиш, слово сбрасывается;
   * URL, e-mail, пути, слова с цифрами (настраивается), смешанные латиница+кириллица,
     «странный» регистр (`hElLo`) — **не трогаем**;
   * одна буква другой раскладки при включённом `convert_single_letters` и назначенном языке приложения — **переводим в назначенный язык**, даже `a`/`I`; иначе слишком короткие слова не трогаем;
   * слово есть в словаре своего языка — **не трогаем**. Это же правило для редких случаев, когда
     **оба** варианта — настоящие слова: автоматически не конвертируем (горячая клавиша работает);
   * конвертированное слово (в т.ч. без 1–2 завершающих знаков препинания: `ghbdtn,` → `привет,`)
     есть в словаре другого языка — **конвертируем**. Слова из 2–3 букв должны входить в 3000 самых частых;
   * ни того ни другого нет в словаре: конвертируем, только если в набранном есть буквенные пары
     (биграммы), нетипичные для его языка, а в конвертированном таких нет, и слово ≥ 4 букв.
     Случайные строки и пароли обычно не проходят.
4. Замена: N раз Backspace (слово + разделитель), затем исправленный текст, раскладка переключается
   на нужную. Если хоть что-то не получается (нет нужной раскладки, нет XTest, нет Accessibility),
   замена **не начинается** — исходный текст остаётся. Если пользователь продолжил печатать до
   выполнения замены — она отменяется.

Словари: по 20 000 самых частых английских и русских слов (hermitdave/FrequencyWords,
CC-BY-SA-4.0), вшиты в бинарник, работают офлайн (~450 КБ).

**Ручная конвертация** (`hotkey`): конвертирует текущее слово или, если оно пустое, последнее
завершённое (вместе с разделителем) — независимо от словаря. Повторное нажатие возвращает назад,
так же отменяется и неудачная автозамена. Сочетание задаётся в окне настроек или через
`typed set hotkey …`. Старые значения `Pause`, `ShiftShift` и `CtrlAltSpace` по-прежнему
понимаются; можно указать любое безопасное сочетание вроде `Ctrl+Shift+P`. Буква или цифра без
Ctrl/Alt/Win не принимается, чтобы не перехватывать обычный ввод. По умолчанию: `Pause` на
Windows/Linux, оба Shift на macOS.

**Вызов окна** (`summon_hotkey`, по умолчанию `Ctrl+Shift+V`): поднимает уже открытые настройки
на вкладке «Сейф» или запускает `typed gui --vault`. Работает и в приложениях из списка исключений (в отличие от
конвертации слова), чтобы можно было подставить логин или карту из сейфа.

**Отмена автоисправления** (`undo_hotkey`, по умолчанию `Ctrl+Alt+Z`, на macOS `Ctrl+Option+Z`).
Сразу после исправления возвращает набранное слово и заносит его в `never_correct`, после этого
Typed его не трогает. `Ctrl+Shift+Z` не используется, потому что во многих программах это «Повторить».
Backspace сразу после исправления тоже отменяет его (`undo_on_backspace`, по умолчанию включено).
CLI: `typed set undo-hotkey <Combo>`, `typed set undo-on-backspace on|off`.

На Windows наши горячие клавиши поглощаются; на Linux (XRecord только наблюдает) и macOS
(listen-only tap) нажатие дойдёт и до приложения — для Pause/Shift это безвредно, для буквенных
сочетаний с модификаторами обычно тоже.

## Wayland: что работает и что нет

Wayland намеренно не даёт обычным приложениям видеть чужие нажатия клавиш, узнавать активное окно
и печатать в чужие окна. Это защита, а не баг, и обойти её «честно» нельзя.

* **Сессия Wayland с XWayland**: LayoutKeeper работает **только для X11-приложений** (запущенных через
  XWayland), нативные Wayland-окна он не видит. Об этом пишется предупреждение при старте.
* **Чистый Wayland** (без `DISPLAY`): программа отказывается запускаться и объясняет причину —
  поддельной «реализации» нет.
* **Правильный путь** — движок метода ввода (IME): **IBus** (GNOME) или **Fcitx5** (KDE, другие).
  Движок получает нажатия *легально* в активном поле, знает, когда поле — пароль
  (`IBUS_INPUT_PURPOSE_PASSWORD`), и сам коммитит исправленный текст. Ядро уже готово к этому:
  `Engine::feed` / `Engine::decide` / `Engine::manual_convert` и C ABI (`lk_autocorrect_word`,
  `lk_convert_layout`) можно вызвать из движка IBus (C/Python через `staticlib`/`cdylib`) или
  Fcitx5 (C++). Память по приложениям в Wayland зависит от композитора: в GNOME — расширение Shell
  (`global.display.focus_window.get_wm_class()` + `Meta.KeyboardManager`), в KDE — KWin script /
  D-Bus `org.kde.KeyboardLayouts`, в Sway/Hyprland — их IPC (`swaymsg -t subscribe window`,
  `swaymsg input type:keyboard xkb_switch_layout`). Это план развития, в репозитории пока не реализовано.

## Безопасность (только локально)

* Нет сетевого кода вообще: ни одна зависимость не ходит в сеть (`serde`, `serde_json`, `dirs`, `log`,
  `env_logger`, `x11-dl`, `windows-sys`). Можно проверить: `cargo tree`.
* Нажатия хранятся **только** в буфере текущего слова (≤ 64 символа) и последнем завершённом
  слове — для ручной отмены. Буфер затирается при сбросе. На диск текст не пишется никогда.
* В конфиг пишутся только идентификаторы приложений, коды раскладок и настройки.
* Буфер обмена не используется.
* На уровне `info` в логи не попадают набранные слова; `debug` показывает только длины и решения.

## New in 0.3.65

- **No CPU use while the settings window is minimized.** The minimized window was hidden to the tray again on every frame, and each hide woke the window up again (~6% CPU). It is now hidden once and a minimized or hidden window draws nothing; with the vault open a once-a-minute wake-up keeps the idle lock working.
- **Brand and product names.** ≈14.2 k new Latin names (phones, electronics, cars, fashion, software, apps, games, websites, crypto, food and drinks, retail) and ≈6.4 k Russian spellings of popular brands with case forms (`реалми`, `сяоми`, `айфона`, `айфоном`, `ютубе`) from Wikidata (CC0) plus curated lists. `realme` is no longer "fixed" to `realm`, and `куфдьу` becomes `realme`. Names are known-only (never offered as fixes); tokens shorter than 4 letters and tokens that read as a real word in the other layout are left out, so wrong-layout conversion is unchanged (100% in the audit).
- **English: no fix that only adds or drops the last letter** (realme → realm, appl → apple); a doubled last letter is still fixed (helloo → hello). False fixes on rare English words 10.4% → 8.6%, synthetic typos fixed 76.2% → 78.4%.
- **Missing space after Russian prepositions and «не»:** `снейросеткой` → `с нейросеткой`, `вофисе` → `в офисе`, `незнаю` → `не знаю`. Only for tokens unknown to every list, when the rest is a frequent word with an ending that fits the preposition, not a name and (except after «не») not a verb. Real words are never split (0 of 63 k sampled forms). Undo like any autocorrection; Settings checkbox «Расставлять пропущенные пробелы» (`fix_missing_spaces`), never in exception apps.

### New in 0.3.64

- **Full-form dictionaries.** 3.16 M Russian word forms (every case, number, gender, tense, participle) and 810 k English forms from OpenCorpora, Hunspell ru_RU / en_US / en_GB, SCOWL, Wiktionary (kaikki.org) and wordfreq. Real words, even rare ones (`скидывать`, `скидываешь`), are never "fixed" into other words; fixes still only target frequent words. False fixes on rare real words: RU 8.7% → 1.5%, EN 13.9% → 4.1%; synthetic typo fix rate 77.6% → 77.0%. Embedded as fst sets (+≈5.5 MB binary, no start-up cost), still fully offline. Sources and licenses: `crates/core/data/README.md`.
- **Undo the last autocorrection: `Ctrl+Alt+Z`** (`Ctrl+Option+Z` on macOS, configurable in Settings). Restores exactly what was typed, with its space/sign and layout, and adds the word to a persistent **never-correct** list.
- **Backspace right after an autocorrection undoes it** (Punto Switcher style): only the first Backspace before any other key, not after Enter/Tab; the word is remembered once you keep typing. Can be turned off in Settings.
- **No more stubborn repeats:** erasing a correction and typing the original again (also with Ctrl+Backspace / Option+Delete) keeps it and remembers it. The conversion hotkey right after an autocorrection also acts as undo.
- The never-correct list is shown on the Words tab (trash icon re-enables correction). Config: `never_correct`, `undo_hotkey`, `undo_on_backspace`; older configs load unchanged.

**Typed** (formerly LayoutKeeper) is a local-only Punto Switcher–style utility:

* **Per-app layout memory** — remembers the keyboard layout (en/ru) you use in each app
  (Windows: exe path, macOS: bundle id, Linux: WM_CLASS) and restores it when the app gets focus;
  the assigned layout is sticky (since 0.2.0): it is re-applied on every focus, and switching the
  layout inside the app never overwrites it (manual changes are left alone after the ~3-second focus grace period). Change it only via `set-app`/`remove-app` or the GUI.
  `auto_learn` (off for new configs) only fills in apps that have no assignment yet.
  Exception apps skip autocorrect only; their assigned layout is still remembered and applied.
* **Settings GUI** — `typed gui` (egui): assign the focused app EN/RU, edit/remove remembered
  apps, toggles, and hotkeys (press-to-assign, plus presets). Separate process that edits the same
  `config.json`; the daemon reloads in ~1 s. A global summon hotkey (default `Ctrl+Shift+V`) focuses
  or starts this window on the Vault tab so the vault can fill the field you just left.
* **Wrong-layout autocorrect** — `зуфсу` → `peace`, `ghbdtn` → `привет`, using embedded 20k-word
  English/Russian frequency lists plus a bigram fallback; URLs, e-mails, digits, mixed scripts,
  odd casing and words valid in the current language are left alone. If both forms are real words,
  nothing is converted automatically.
* **Manual convert hotkey** (any safe combo; Pause by default, Shift+Shift on macOS) flips the
  current or last word regardless of dictionaries; press again to undo. Configure it in the GUI
  or with `set hotkey Ctrl+Shift+P`.

Build: `cargo test && cargo build --release`. Run: `typed` (`status`, `set-app <id> <en|ru>`,
`list-apps`, `convert`, `check`, `set …`).

Platforms: Linux X11 implemented and tested under Xvfb; Windows and macOS implemented against the
native APIs and type-checked for their targets, not yet run on real hardware; Wayland and mobile are
documented only (IME is the real path). macOS needs **Input Monitoring** + **Accessibility**;
Windows cannot touch elevated windows (UIPI); X11 needs RECORD/XTEST.

Security: no network code, no telemetry, no clipboard use; typed text exists only in an in-memory
current/last-word buffer and is never written to disk or logged at info level.

### Vault (0.3.0)
Optional local encrypted vault for logins and cards in `typed gui` → "Сейф" tab.
`vault.bin` next to `config.json`; Argon2id + XChaCha20-Poly1305; the master password cannot be recovered.
Unlocked only in GUI memory; locks on close/idle timeout. Entries are added only manually — the keyboard hook
never harvests input. Lists show labels/usernames and card last 4 only; CVC is optional. Filling happens only on
a button click: the GUI minimizes itself and types (SendInput/XTest/CGEvent, no clipboard, no network) into the
focused app, refusing if that is Typed itself or a different app than shown.
Crypto crates: `argon2`, `chacha20poly1305`, `rand`, `zeroize` (RustCrypto, MIT/Apache-2.0). Project license: MIT.
