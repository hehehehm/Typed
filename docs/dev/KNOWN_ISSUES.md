- Если один набор — соседняя перестановка двух частых слов, без решающего контекста берётся более ранняя перестановка. Относительно исходного слова для rank < 1000 это 47 неверных, пропусков нет; все 47 совпадают с правилом (`wiht` → `whit` → `with`, `amry` → `mary` → `army`, «номре» → «норме» → «номер»). Для rank < 5000 таких 164, пропусков нет.
- Относительно самого правила ранней перестановки: 55 несовпадений (почти все — более частый перевод раскладки перестановки более редкого своего слова, первое «буью» → `,em.` → «убью») и 5 пропусков у редких слов (ранг ≥ 8706: «девй», «крони», «линтет», «кроней», «впаал»).
- Layout+typo с соседней клавишей всё ещё пропускает наборы с цифрами, путём/URL и те, где латинский набор — известная форма исходного языка или typo после перевода — не сосед и не перестановка (`enuf` для «утра»).
- Гейт «не хуже 0.3.86» не пройден: 58 метрик, выше доля неверных typo 1/2 и часть склеек с предлогом, см. `METRICS.md`.
- Короткие русские слова (длина 2–4, ранг < 20000), набранные латиницей в нижнем регистре: 434 из 1821 не переводятся даже в одиночку. Главные причины: латинский набор сам есть английское словарное слово (`vs` → «мы», `here` → «руку») или русское слово реже порога 3000 (`тим` r3031, «увы» r5832). После английского слова ещё 22 случая, где латинский набор засвидетельствован в английском корпусе или это не full-form (`kb` → «ли», `ns` → «ты»).
- Опечатка «озвучб» сама по себе не становится «озвучь». После исправления «jpdex,» → «озвучб» пользователь может стереть «б» и набрать «ь»: раскладка остаётся русской, слово больше не трогают.
- `ghbdtn,` и `ghbdtn.` без пробела не исправляются: запятая и точка в английской раскладке могут быть буквами «б» и «ю». После пробела уже работает: «привет,», «привет.».
- `руддщ,` по-прежнему даёт `hello?`, а не `hello,`.
- Одиночное слово с соседней перестановкой и другой правкой одной буквы решается перестановкой: «грои» → «гори» (не «герои»), «оплет» → «полет», «штку» → «штук», `ksis` → `skis`, `potic` → `optic`. Так решил пользователь; это главная причина роста доли неверных typo 1 против 0.3.86.
- Склейка с предлогом из одной буквы теперь часто читается как лишняя буква: «спесни» → «песни», «иимя» → «имя», «кзамке» → «замке» (space_glued_prep 90.38 против 98.70). В каком коммите после 7575ab2 это появилось, не проверено.
- Редкие английские полные формы переводятся с опечаткой: `huhs` → «игры», `jere` → «руку», `indre` → «штуку» (191 случай в fp_full_forms). Это цена правила для `enuf` → «утра».
- «провести уладит» не становится «провести аудит»: «уладит» — словарная форма, «аудит» нет в ранжированном словаре (есть только в корпусе).
- `talkes` → `takes`, а не `talks`: обе правки — одна лишняя соседняя буква.
- `issuse` одиночно → `issues`; после `the` → `issue`.
- `amry` одиночно → `mary` (самая ранняя перестановка), после `the` → `army`.

## Ложные срабатывания на словаре (typist_sweep)

`fp_full_forms`: 323 из 11,9 млн форм (в 0.3.86 было 321).

- Пары слов, которые есть в обеих раскладках: `kbps` ↔ «лизы», `иуде` → `belt`, `руру` → `hehe`. Любое правило по частоте снижает эти ложные ровно на столько же, на сколько теряет перевод раскладки. Опыт с порогом частоты откатили (см. `DECISIONS.md`).
- Перестановка трёх букв частого слова: `nad` → `and`, `obj` → `job`, `итр` → «три», `кат` → «так». Это правило из 0.3.83, оно ловит реальные опечатки чаще, чем ломает.
- Двухбуквенные сокращения: `nf` → «та», `pf` → «за».

`fp_ngram_phrase`: 553 из 783 тыс. фраз (в 0.3.86 было 495).

- Одиночные буквы: `t b` → `t и`, `f a` → `а a`.
- Названия и сокращения: «законодательства рф» → «законодательства ha», `acf fiorentina` → `act fiorentina`.
- Лишний пробел внутри слова: `add ons` → `addons`, «абу бакр» → «абубакр». Работает только на Normal и Aggressive.

## Доля неверных исправлений выросла относительно 0.3.83

Больше исправлений, но доля неверных выше на десятые доли процента:

- `context_eval`: EN typo1 3,20 → 3,58%, EN typo2 14,2 → 16,5%, RU typo1 3,33 → 3,89%, RU typo2 9,4 → 10,6%.
- `correction_eval`: EN typo 1 1,9 → 2,5%, EN typo 2 7,3 → 8,3%, RU typo 3 5,9 → 6,1%.
- `unknown-fp`: EN lower 17,3 → 17,7%, RU lower 28,9 → 29,0%.

Причина: шумовой канал и разбиение склеек выбирают кандидата по частоте без контекста фразы. Пример: «это мбыло давно» → «это мыло давно» вместо «это было давно».

## Пропуски

- Опечатки в словах с заглавной буквы исправляются хуже строчных: typo1 Title 89,2% против 92,8% lower. Включение канала для Title увеличило `unknown-fp` Capitalised.
- Пропуск буквы 80,8%, соседняя клавиша 89,4%, перестановка 90,1%. Промахи в основном в редких словах, где ближе частое слово.
- Склейка двух слов без предлога 79%, пробел соседней клавишей 54%.
- Слова 2–3 букв строчными в чужой раскладке: RU→EN 21,9%, EN→RU 19,1%. Не усиливаем специально, это правило.
- Тестеры: у `zlodey` около 35% ошибочных слов не исправлено. Это слова с двумя и более ошибками, цифры внутри слова, ошибки, дающие другое реальное слово, и слова из одной-двух букв.
